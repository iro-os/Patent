# KIPO 공식 특허출원 서식 (별지 제14~17호) — 우리 문서 생성의 기준 템플릿

출처: 특허청 공식 서식 견본 (`MoIP Document 14.hwp`, 사용자 제공 2026-06-07).
이 문서는 우리 도구가 따라야 할 **공식 포맷의 단일 기준(source of truth)** 이자 생성 시 **few-shot 예시**다.
예시 발명("건축용 금속재 장식판 보호피막")은 특허청 샘플이며 엑셀바이오와 무관 — **구조 예시용**.

코드 매핑: `lib/kipo/sections.ts` (`KIPO_SECTIONS`, `KIPO_ABSTRACT`, `KIPO_APPLICATION_FIELDS`, `formatKipoCitation`).

| 별지 | 서식 | 우리 도구의 역할 |

| 제14호 | **특허출원서** (서지/행정) | 일부 자동 채움(명칭, **§30 공지예외적용/공개형태/공개일자**). 출원인코드·수수료·서명은 출원인/변리사 |

## 별지 제15호 — 명세서 구조 (순서 = 문서 레이아웃)

```
【발명의 명칭】            국문 {영문}
【기술분야】
【배경기술】
(【선행기술문헌】)          ← 선행기술 리서치 결과가 매핑됨
   (【특허문헌】)
   (【비특허문헌】)
【발명의 내용】
   【해결하려는 과제】
   【과제의 해결 수단】       ← 독립항(청구항1)을 풀어쓴 것
   【발명의 효과】
【도면의 간단한 설명】
【발명을 실시하기 위한 구체적인 내용】
(【실시예】)
(【산업상 이용가능성】)
(【부호의 설명】)
(【수탁번호】)
(【서열목록 자유텍스트】)
【특허청구범위】
   【청구항 1】 …
```
( ) = 조건부/선택 항목.

## 선행기술문헌 인용 형식 (그대로 따를 것)

- **특허문헌**: `[문헌1] US 5635683 A (MCDERMOTT, R. M.) 1997.06.03.`
  `[문헌2] JP 10-105775 A 1998.04.24, 5쪽, 3-15줄, 도면1`
- **비특허문헌**: `[문헌1] WALTON, Herrmann. 초고주파 양자 이론. 런던: Sweet와 Maxwell, 1973, Vol.2, ISBN 5-1234-5678-9, 138-192쪽`

→ `formatKipoCitation(ref, index)` 가 source에 따라 특허문헌/비특허문헌으로 생성.
우리 PubMed/OpenAlex 결과 = **비특허문헌**, Google Patents/KIPRIS = **특허문헌**(Phase 1 후반).

## 명세서 작성 예시 (구조 exemplar — 특허청 샘플 발명)

> 생성 모델이 "등록 특허 수준"의 문장 톤·구성을 학습하는 few-shot 기준. 내용이 아니라 **형식·문체**를 본다.

**【발명의 명칭】** 건축용 금속재 장식판의 보호피막 형성방법 {The method of forming the protective film on the metallic decorative panel for building}

**【기술분야】** 본 발명은 건축용 금속재 장식판의 피막 형성방법에 관한 것으로, 더욱 상세하게는 우레탄아크릴 물질과 전리활성화 물질이 혼합되어 있는 수지원액을 이용하여 수지전착(樹脂電着)방법으로 금속재 장식판의 특정 부분에 피막을 형성시킬 수 있도록 하는 … 방법에 관한 것이다.

**【배경기술】** 일반적으로 엘리베이터 케이지의 내부나 도어 또는 건축물을 미려하게 장식할 목적으로 … (도 1 참조, 종래공정 서술) … 금 증착부가 손상·분리되어 수명이 단축되는 문제점이 발생하게 된다.

**【선행기술문헌】**
- 【특허문헌】 [문헌1] US 5635683 A (MCDERMOTT, R. M.) 1997.06.03. / [문헌2] JP 10-105775 A 1998.04.24, 5쪽, 3-15줄, 도면1
- 【비특허문헌】 [문헌1] WALTON, Herrmann. 초고주파 양자 이론. 런던: Sweet와 Maxwell, 1973 …

**【발명의 내용】**
- **【해결하려는 과제】** 본 발명은 … 보호층의 피막을 형성시킴으로서 이물질 제거가 용이하고 금 증착부의 손상·분리를 방지하여 반영구적 수명을 갖도록 하는 … 제공하는데 그 목적이 있다.
- **【과제의 해결 수단】** 본 발명은 금속판의 다수 부분을 에칭시켜 … 마스킹 잉크를 도포하는 단계, … 수지전착시켜 보호피막을 형성하는 단계, … 150℃에서 약 2시간 열처리하는 단계, … 마스킹 잉크를 제거하는 단계로 이루어진 것에 특징이 있다.
- **【발명의 효과】** 본 발명은 … 이물질 제거가 용이하고 금 증착부의 손상·분리를 방지하여 반영구적 수명을 가질 수 있다.

**【도면의 간단한 설명】** 도 1은 … 단면도. 도 2는 … 구조도. 도 3 내지 도 6은 … 공정도.

**【발명을 실시하기 위한 구체적인 내용】** 본 발명을 첨부된 도면을 참조하여 상세히 설명하면 다음과 같다. 도 2는 … 보호피막 형성장치(7) … (도면 부호 사용한 상세 실시 설명) …

**【특허청구범위】**
- **【청구항 1】** 금속판의 다수 부분을 에칭시켜 특정 무늬모양을 형성하는 건축용 금속재 장식판에 있어서, 상기 금속판의 보호피막을 형성하고자 하는 특정부분을 제외한 나머지 부분에 마스킹 잉크를 도포하는 단계, … 로 이루어진 것을 특징으로 하는 건축용 금속재 장식판의 보호피막 형성방법.

**별지 제16호 【요약서】 → 【요 약】** (발명 요지 1문단) **+ 【대표도】** 도1

### 관찰 (생성 규칙으로 반영할 것)
1. **과제의 해결 수단 ≈ 독립항의 산문화** — 둘이 거의 동일 문장. 청구항↔명세서 일관성(antecedent basis)의 근거.
2. **도면 부호 일관성** — 본문/청구항/부호의 설명에서 같은 번호(예: 금속판(1), 에칭부(3))를 끝까지 동일하게.
3. **"~것을 특징으로 하는 [명칭]."** 으로 끝나는 독립항 종결 어법.
4. **선행기술문헌**은 배경기술 뒤, 발명의 내용 앞. → 우리 리서치 파이프라인의 자연스러운 출력 위치.
