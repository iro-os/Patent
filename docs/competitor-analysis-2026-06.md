# 특허 AI — 경쟁사 분석 & 전략 리포트 (2026-06)

> 9개 에이전트 병렬 웹 리서치(국내/해외 드래프팅·검색·의료버티컬·가격GTM) + 핵심 결론 4건 반증검증. 출처 130+.
> 우리 제품: 의료기기 회사용, 대화형(plan-mode) 발명 인테이크 → PubMed/OpenAlex 선행기술 → 차별성 분석 → KIPO 명세서·청구항 초안(§30 처리).

---

## 0. TL;DR — 한 장 요약

**가장 중요한 교정 (가설 1개 반증됨):**
"국내 경쟁사는 검색·분석만 하고 명세서 드래프팅은 안 한다"는 전제는 **틀렸다.** GenIP(Gen-D)·PatentSpace·Keywert Insight는 **이미 한국어 명세서를 풀로 생성**한다. → **"우리는 초안을 쓴다"는 것 자체는 차별점이 아니다(이미 국내에서 상품화됨).**

**그러나 방어 가능한 차별성 3축은 검증 결과 그대로 살아있다 (3건 모두 반증 실패 = 확정):**
1. **의료/바이오 도메인 특화 + PubMed/OpenAlex(과학문헌)을 1차 선행기술로** → 국내 어떤 IP-AI도 안 함. 전 세계에서도 드물다.
2. **발명자(CEO) 직접용 대화형 인테이크** → 국내 경쟁사는 전부 **변리사 도구**. 발명자 직접용은 사실상 공백.
3. **KIPO-네이티브 (§30 공지예외, 한국어 별지 제15호, 그리고 의료행위 청구항 배제 등 한국 의료특허 특유 규칙)** → 누구도 안 다룸.

**결론:** 포지셔닝을 "AI가 명세서를 써준다"(레드오션)에서 → **"한국 의료기기 발명자를 위한, 과학문헌 기반·KIPO 의료특허 특화 사전(pre-filing) 인텔리전스"**로 이동. 3축 교집합을 채우는 제품은 2026년 6월 현재 **시장에 존재하지 않음**(반증검증 high confidence).

## 1. 시장 구조

### 국내 (한국) — 2개 진영 + 신생 드래프팅
- **검색·분석 인큐번트:** WIPS(윕스, #1, 5,000+ 기업) · WERT(키워트, 300M 특허·PlutoLM) · 위즈도메인 · 광개토연구소 · 애니파이브 · 타날리시스. → 대부분 검색/분석, 일부 "초안 아웃라인" 추가.
- **명세서 드래프팅 신생(2023~2026):** **GenIP/Gen-D**, **PatentSpace**, **PatentFT/EzPatent**(출시 전), **DRIFT**(스텔스), **Keywert Insight**(인큐번트의 드래프팅 진입).
- **공통점:** 전부 **변리사(변리사 사무소) 타깃.** 발명자 직접용·의료 특화·과학문헌(PubMed) 결합은 **아무도 안 함.**

### 해외 — 자금력 큰 horizontal 드래프팅 다수
- **풀스택 드래프팅:** Solve Intelligence($55M, ARR $12M) · DeepIP($40M+) · Patlytics($65M) · Rowan(Clarivate 인수) · Edge(YC) · Paximal/Specifio · XLSCOUT.
- **거의 전부 USPTO/EPO-first, 변리사·로펌 판매, 영어.** 한국어 명세서 네이티브 생성 = **0개.**

### 의료 버티컬 — 사실상 공백
- 의료기기 특화 특허 드래프팅 제품 = **없음.** 가장 근접한 **i-GENTIC AI**는 의료 도메인이지만 **FDA 510(k) 규제 검토**용 — 특허가 아님(인접 레인).
- KIPO 자체 AI(LG AI Research)는 **심사관 내부용**, 출원인용 아님.

## 4. 기능 갭 분석 — 두 종류로 나눠서 본다

### A. "테이블 스테이크스" 갭 — 경쟁사는 이미 있는데 우리는 없는 것 (있어야 경쟁 가능)

| 갭 | 누가 이미 함 | 왜 시급 | 우선순위 |
|---|---|---|---|
| **특허 DB 검색 (KIPRIS 우선, +Espacenet/USPTO)** | 전 경쟁사 | **지금 우리는 PubMed/OpenAlex(논문)만 본다. 의료기기 신규성은 특허문헌이 핵심인데 그걸 안 본다 = 가장 관련성 큰 선행기술을 놓칠 수 있음 = 특허 도구로서 위험.** 과학문헌은 차별점이지 *대체재가 아님* | **P0 (최우선)** |
| **풀 명세서 산문 생성** (현재 scaffold만) | GenIP·PatentSpace | 제품의 핵심 산출물 | **P0** |
| **도면 생성/해석 (Vision AI)** | PatentSpace·GenIP·DeepIP·Rowan | 의료기기 특허는 도면 중심 | **P1** |
| **DOCX export** | PatentSpace 등 | 변리사 핸드오프 필수 | **P1** |
| **청구항 정합성 (선행기재·antecedent basis·완성도 체크)** | Patlytics·ClaimMaster·PatentSpace | 초안 품질 신뢰 | **P1** |
| **발명신고서 파일 파싱 (HWP/PDF/PPT)** | Edge·DeepIP 등 | 현재 첨부만 되고 파싱 안 됨 | **P2** |

### B. "해자(moat)" 기능 — 아무도 안 하는, 의료×KIPO 특화 (여기에 자원을 쏟아라)

| 기능 | 왜 강력한 해자인가 |
|---|---|
| **🔑 KIPO 의료행위 청구항 배제 처리** | 한국은 **인간 대상 의료행위(치료·수술·진단 방법) 특허 불가**. 청구항을 **장치·조성물·용도 청구항으로 자동 전환**하도록 유도. 일반 도구·해외 도구는 여기서 틀린다(Qatent가 생명과학에서 무너진 바로 그 지점). **의료 특화 + KIPO 네이티브가 동시에 필요한, 흉내내기 어려운 기능.** |
| **MFDS(식약처) 규제 연계** | 의료기기 등급(1~4급)·GMP·임상 데이터 요구를 특허 전략과 연결. i-GENTIC가 규제 레인의 가치를 증명함 — **우리는 IP×규제 교차점을 선점 가능.** |
| **§30 공지예외 — 의료 맥락 강화** | 의료 발명자는 **학회 발표·포스터·논문 선공개가 매우 흔함** → §30 grace가 특히 자주 필요. 경쟁사 누구도 안 다룸. 이미 우리가 가진 기능 → 의료 맥락으로 심화. |
| **의료 온톨로지 grounding (MeSH·IPC A61·UMLS)** | 검색 정밀도 + 청구항 용어 정확도 동시 향상. |
| **임상 근거 연계 (ClinicalTrials.gov)** | 발명을 임상 랜드스케이프와 연결(PatSnap/Questel이 검색에서만 함 — 우리는 *드래프팅까지* 연결). |
| **ST.26 서열목록** (체외진단/바이오마커 디바이스 시) | 진단기기로 확장 시 필요. Patlytics/DeepIP/Rowan만 보유. |

## 5. 가격 & GTM (리서치가 매우 구체적)

- **한국 변리사 비용:** 출원 ₩1.5–2.5M, 등록까지 총 ₩2–4M.
- **정부 보조:** **IP 바로지원** ₩2.1M/건(기업 40%=₩840K 부담) · **KIPA CIPO** 8개월 최대 ₩70M · **TIPS** 최대 ₩5B(딥테크 ₩15B, IP비용 인정).
- **권장 가격:** **건당 ₩300K–800K** — *정부 보조 하한선(₩2.1M) 아래로* 의도적 배치 → **"법률 서비스"가 아니라 "사전(pre-filing) 인텔리전스"**로 포지셔닝.
- **🔑 변리사법 제약 (반드시 준수):** 비(非)변리사 주체의 특허 대리 행위 금지. → 제품은 **"초안·인텔리전스"이고 최종 출원은 변리사를 통한다**는 선을 명확히. 이걸 어기면 법적 리스크 + 변리사 채널 적대화.
- **시장 순풍:** 한국 의료기기 특허출원 2020→2024 **1.4배↑**, 2024 출원 40%+가 AI 청구항 포함, 바이오헬스 = 국가전략산업.
- **채널:** CIPO/TIPS 참여 기업 = 예산 승인된 고의향 출원인 → **타깃 세그먼트.**

## 7. 권장 액션 (우선순위)

1. **포지셔닝 재정의** — "AI가 명세서를 써준다"(레드오션) → **"한국 의료기기 발명자를 위한 과학문헌 기반·KIPO 의료특허 특화 사전 인텔리전스."** (변리사 대체 아님, 변리사법 안전.)
